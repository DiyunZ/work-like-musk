# Artwork

The README hero is original AI-generated editorial artwork created with the built-in imagegen tool. Its layout follows principles of restrained product presentation, clear typography, generous spacing, and subtle material depth. The HUD icons and their placement beside a task title are informed by this repository's actual English native preview.

The workspace shown in the poster is an interface illustration, not a literal screenshot. Its task and messages are synthetic. All visual text is English and contains no private project data. The portrait does not imply an endorsement.
